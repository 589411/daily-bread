# 原文彩蛋 — 生產線 HARNESS.md（流程＋踩坑紀錄）

> 這是「怎麼量產下一批」的操作手冊，以及第一批（2026-07-05，26筆）踩過的坑。
> 規格本身在 RULES.md；本檔記錄流程與教訓，每批結束後更新。

## 1. 生產流程（已驗證可行）

```
主模型（高階）：定規格 → 派工 → 審核 → 修正 → 驗證 → 合併
  │
  ├─ sub-agent A（opus）   ─┐
  ├─ sub-agent B（opus）   ─┤ 並行生成，各 6-8 筆
  ├─ sub-agent C（sonnet） ─┤ 輸出 draft_X.json
  └─ sub-agent D（sonnet） ─┘
  │
  L1 程式驗證 tools/validate_insights.py（原文逐節比對）
  L2 主模型逐筆 rubric 審核（RULES.md §6 R1-R5）
  → 全部修正 → ALL OK → 合併進 data/insights.json → 刪 draft → commit
```

派工 prompt 要點（每個 agent）：
1. 必讀 RULES.md §2–§4 ＋ insights.json 的黃金範例（jer.1.11）
2. 給明確主題清單（每筆指定經文與現象，不要讓模型自選——自選會挑最俗的）
3. **若環境可連網，強制要求先抓原文與和合本逐節自驗再交件**（見 §3 教訓 9）
4. 要求回報「最沒把握的一筆與原因」——這個自評非常準，審核先看它

## 2. 第一批結果統計

- 4 agents × 6-7 筆 = 25 筆草稿 + 1 筆黃金範例 = 26 筆
- L2 審核抓出 **~10 個實質錯誤**（下表），L1 驗證再抓出 3 個漏網
- 有連網自驗的 agent（B、D）：cuvQuote 零錯誤；憑記憶寫的（A、C）：錯誤集中
- opus 與 sonnet 的差距 **小於**「有無自驗管道」的差距——**驗證通道比模型等級重要**

## 3. 踩坑清單（審核與出題時逐條對照）

1. **和合本其實有括號註**：創4:1「該隱（就是得的意思）」、11:9「巴別（就是變亂的意思）」、
   25:26「雅各（就是抓住的意思）」。條目寫「中文讀者完全看不出」是不準的——和合本譯者
   早就意識到雙關並用註釋補救。正確說法：「註釋補回了意思，補不回聲音」。
   → 出題規則：名字詞源類，先查和合本有無括號註。
2. **cuvQuote 憑記憶必錯**：「好憐憫」寫成「喜愛憐憫」、「隨後又生了」寫成「後來生的」、
   出17:12「發沉」寫成「疲乏」。→ 引文一律逐字核對，不確定就縮短或省略。
3. **和合本舊字體**：女性第三人稱用「他」不用「她」（創2:23、撒上4:21）；「那裡」不用「哪裡」。
4. **和合本破折號**：「耶和華─你的神」中間有全形破折號，引文跨過它會比對失敗（申6:5、何14:1）。
5. **標點差異**：引文結尾的句號／分號要照原文（創5:29 是「安慰我們；」）。
6. **詩篇篇題位移**：有篇題的詩篇，WLC 把篇題算第1節（詩42:1＝篇題），和合本42:1＝WLC 42:2。
   詩119 無篇題、無位移。→ 凡詩篇錨點，先確認該篇有無篇題。
7. **中希分節位移**：何13:16（中）＝WLC 14:1，整章差一節。瑪拉基、約珥、詩篇多處同理。
   → ref 一律用 WLC/bolls 節號，essay 註明差異，cuvVerse 填和合本節號。
8. **match 要填實際字形不是字根**：得1:6 שוב 以 wayyiqtol「ותשב」出現，子音串 שוב 不連續。
   → match 填該節實際出現的形（含前綴／變位）。
9. **驗證源本身也會有洞**：bolls WLC 何14:2 缺開頭的 שׁ（兩次獨立抓取確認）。
   → 比對失敗時先看原文是否合理，不要盲目改條目遷就資料源；改用鄰近節錨定並記錄。
10. **簡體字滲入**：sonnet 產出混入「运行」「这」。→ 審核時 grep 常見簡體字。
11. **essay 引入 words[] 之外的原文詞**：允許的例外＝該詞已由 crossRef 錨定；其餘要求補進 words[] 或改寫。
12. **TR 與 NA28 異文**：約21:15 TR 作「約拿的兒子」，NA 作「約翰的兒子」（和合本從 NA 傳統
    並自己加了括號註「在太16:17稱約拿」）。驗證文本是 TR，essay 涉及異文必須註明。

## 4. 驗證器使用備註

- 正常（有網路）：`python3 insight/tools/validate_insights.py` → 自動抓 bolls 並快取到 `tools/.cache/`
- 無網路：`--offline` 只做 schema 檢查；或預先把單節寫成 `tools/.cache/V_{WLC|TR|CUV}_{book}_{ch}_{v}.json`
- `.cache/` 已加入 .gitignore，不進 repo
- 單節端點：`https://bolls.life/get-verse/{trans}/{book}/{chapter}/{verse}/`（比整章省流量）
